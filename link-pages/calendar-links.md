# Получение ссылок

Для настройки календарей, нужно сначала получить ссылки на эти календари.

## Алгоритм действий

1. Настраиваем группы и преподавателей на одной из платформ
2. Запрашиваем там же ссылки на календари
3. Копируем полученные ссылки
4. Вставляем ссылки в нужный календарь

## Поддерживаемые календари
